# Cấu trúc cây thư mục
```
│   AGENTS.md --> file mô tả dự án
│   problem-description.md --> file mô tả bài toán
│   README.md
│   
├───diagrams --> thư mục chứa các sơ đồ
│   ├───sequence(incomplete) --> thư mục chứa các sơ đồ tuần tự
│   │       ai-chatbot.pu
│   │       authentication.pu
│   │       pc-case-management.pu
│   │       
│   └───usecase(incomplete) --> thư mục chứa các sơ đồ use case
│           usecase.md
│           usecase.pu
│           
├───requirement-spec --> thư mục chứa các tài liệu phân tích yêu cầu
│       requirement.md
│
└───[tài liệu thiết kế hoặc các tài liệu khác]
```

# Sử dụng AI để tạo ra các file markdown (.md) và các file plantuml (pu) cho dự án.
Cho AI đọc file AGENTS.md và file problem-description.md (nếu cần thiết) để tạo ra các file markdown (.md) và các file plantuml (pu) cho dự án.

## Xem sơ đồ trực tiếp trong VS Code bằng extension PlantUML. Cài đặt extension PlantUML trong VS Code, sau đó mở file .pu và nhấn `Alt + D` để xem sơ đồ trực tiếp, có thể kéo tab PlantUML Preview sang cùng tab với file đang mở để xem được rộng hơn.
